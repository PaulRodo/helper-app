# Научпоп-поиск: обновление

Три файла:

- `index.html`: обновлённый апп (замени им старый на GitHub Pages)
- `worker.js` и `wrangler.toml`: бэкенд на Cloudflare Workers

Без Worker апп работает как раньше. Значки надёжности (мета-анализ, РКИ, обсервационное, животные, препринт), журнал в карточке и ссылки на ВОЗ/NHS/Cochrane работают сразу. Всё, что требует Claude (умный поиск, перевод, сценарий, уведомления), включается после запуска Worker.

## Запуск Worker (один раз, ~10 минут)

```bash
npm i -g wrangler && wrangler login
wrangler kv namespace create KV          # скопируй id в wrangler.toml
# впиши свой Telegram ID в ALLOWED_USER_IDS (узнать: @userinfobot)

wrangler secret put ANTHROPIC_API_KEY    # ключ из console.anthropic.com
wrangler secret put TELEGRAM_BOT_TOKEN   # токен бота из @BotFather (тот же бот, что открывает апп)
wrangler secret put TG_WEBHOOK_SECRET    # любая длинная случайная строка
wrangler secret put APP_TOKEN            # необязательно: пароль для открытия апп вне Telegram
wrangler deploy
```

Подключи бота к Worker (подставь свои значения):

```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -d "url=https://nauchpop-api.<твой-поддомен>.workers.dev/tg" \
  -d "secret_token=<TG_WEBHOOK_SECRET>"
```

В Anthropic Console включи **web search** для организации (нужно для сверки ВОЗ/NHS/Cochrane). Если не включить, остальное работает, а эта карточка покажет «Не нашёл».

Открой апп → ⚙️ → вставь адрес Worker → Сохранить. Либо впиши его в константу `DEFAULT_WORKER` в начале скрипта в `index.html`.

## Что где

| Функция | Где |
|---|---|
| Значки типа доказательств, журнал | вкладка «Статьи» (данные PubMed и Europe PMC) |
| ВОЗ · NHS · Cochrane | карточка над выдачей. Для спорных тем открывается сама, иначе кнопка «Сверить позиции» |
| Умный поиск | чип «✨ Умный поиск»: запросы по описанию, ранжирование, краткий пересказ статей |
| Перевод | кнопка «Перевести выдачу на русский» над результатами |
| Фактчек | вкладка «Сценарий» → «Проверить факты» |
| b-roll | вкладка «Сценарий» → «Подобрать b-roll», переключатель Видео/Фото |
| Уведомления | ⚙️ → «Подписки», либо в боте: `/follow тема`, `/list`, `/unfollow 1`, `/digest` |

## Что важно знать

- **Доступ.** Worker принимает запросы только из твоего Telegram (подпись initData и список `ALLOWED_USER_IDS`), поэтому ключ Claude в браузер не попадает и чужие его не потратят.
- **Бот должен знать тебя.** Один раз напиши ему `/start`, иначе он не сможет присылать уведомления.
- **Фактчек читает аннотации, а не полные тексты.** Вердикты «подтверждено / частично / противоречит» нужны, чтобы быстро найти слабые места, а не чтобы заменить проверку источника перед публикацией.
- **Значок типа исследования** берётся из тегов PubMed и MeSH. Если автор журнала указал тип неверно, значок тоже ошибётся.
- **Стоимость.** Haiku (запросы, перевод, ранжирование) стоит копейки на запрос. Sonnet включается только в фактчеке. Сверка ВОЗ/NHS/Cochrane использует веб-поиск и кэшируется на 7 дней.
- Названия моделей меняются в `wrangler.toml` (`MODEL_FAST`, `MODEL_SMART`).
